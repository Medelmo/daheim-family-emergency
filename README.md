# Daheim – Familien-Notfallplan

A free, offline-first German/Arabic family emergency-preparedness Progressive Web App (PWA).

See the app at the GitHub Pages site once deployment is enabled. The application stores household entries locally in your browser using IndexedDB. No family inventory or checklist data is sent to GitHub.

## Features
- Installable PWA with offline app shell
- IndexedDB local storage
- German and Arabic interface with RTL support
- Supplies inventory, expiry tracking and checklist
- Water needs calculator
- JSON backup and restore

## Privacy
The source code is public. User-entered household data remains in the browser on the device. Do not commit backup JSON files or personal data.
